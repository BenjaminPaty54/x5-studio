X5 Studio
MIDI : en attente
C3–C5
Moniteur SysEx

Mise en route

  1. Relie le X5 à l'ordinateur (interface MIDI USB : MIDI OUT du X5 → IN de l'interface, IN du X5 ← OUT). Le port TO HOST fonctionne aussi avec un pilote série.
  2. Sur le X5 : GLOBAL → MIDI Filter → EX = ENA (sinon aucun SysEx ne passe). Pour écrire : Memory Protect Program = OFF.
  3. Ouvre cette page dans Chrome ou Edge, accepte l'accès MIDI, choisis les ports puis clique Détecter (le canal global est trouvé automatiquement).
  4. Si Chrome refuse l'accès MIDI quand la page est ouverte comme fichier, lance dans le dossier de la page python3 -m http.server puis ouvre http://localhost:8000/x5studio.html.
  5. Mets le X5 en mode PROG sur le son à retoucher et clique ⇩ Lire le X5.

Raccourcis

  • Clavier de l'ordinateur = clavier musical (rangée du milieu = touches blanches, rangée du dessus = noires), W/X (AZERTY) ou Z/X (QWERTY) = octave.
  • Espace = test · Ctrl/⌘+Z = annuler · Ctrl/⌘+Maj+Z = rétablir.
  • Double-clic sur un curseur = valeur d'origine. Molette = réglage fin.
  • Bouton SysEx : petite fenêtre (déplaçable, redimensionnable par le coin) qui montre chaque message envoyé ↑ et reçu ↓, traduit en clair. Le curseur Délai ajoute une pause après chaque SysEx (20 ms par défaut).
  • Les macros de l'onglet Rapide reviennent au centre : chaque geste ajoute ou retire par rapport au son actuel.

Limites

Cette version édite uniquement les Programs (sons). Les Combinations, les réglages Global et les paramètres internes des effets ne sont pas encore éditables.

Protocole : Korg SysEx, Model ID 36h (commun X5 / X5D / X5DR / 05R/W). Paramètres en direct : fonction 41h ; son complet : fonction 40h.
