SysEx monitor

Getting started

  1. Connect the X5 to the computer (USB MIDI interface: X5 MIDI OUT → interface IN, X5 IN ← interface OUT). The TO HOST port also works with a serial driver.
  2. On the X5: GLOBAL → MIDI Filter → EX = ENA (otherwise no SysEx gets through). To write: Memory Protect Program = OFF.
  3. Open this page in Chrome or Edge, allow MIDI access, pick the ports, then click Detect (the global channel is found automatically).
  4. If Chrome refuses MIDI access when the page is opened as a file, run python3 -m http.server in the page's folder, then open http://localhost:8000/x5studio.html.
  5. Put the X5 in PROG mode on the sound you want to edit and click ⇩ Read X5.

Shortcuts

  • Computer keyboard = music keyboard (middle row = white keys, row above = black keys), Z/X (QWERTY) = octave.
  • Space = test · Ctrl/⌘+Z = undo · Ctrl/⌘+Shift+Z = redo.
  • Double-click a slider = original value. Mouse wheel = fine adjustment.
  • SysEx button: a small window (movable, resizable from its corner) showing every message sent ↑ and received ↓, decoded in plain words. The Delay slider adds a pause after each SysEx message (20 ms by default).
  • The macros on the Quick tab spring back to the centre: each gesture adds to or takes away from the current sound.
  • The flags at the top right change the interface language.
  • Essential / Full (left of the tabs): Essential keeps the main settings, Full shows every Program parameter. Both modes edit the same sound.
  • ● Editing / ○ Play button: shows whether the X5 is in edit mode. One click hands control back to it (Program mode); it is also put back in play mode when you close the page. If the X5 rejects a change (for example after using its front panel), the app puts it back in edit mode and resends the sound.

Limitations

This version edits Programs (sounds) only, effects included (Full view). Combinations and Global settings cannot be edited.

Protocol: Korg SysEx, Model ID 36h (shared by X5 / X5D / X5DR / 05R/W). Live parameters: function 41h; full sound: function 40h.
